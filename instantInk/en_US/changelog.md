# 2026-06-07

First version of the HP instantInk plugin (instantInk)
 - Sign in to your HP Smart account via API (cloud)
 - Local connection to the printer (if supported)
 - Retrieving plan information: plan period, number of pages included in the plan, number of pages carried over, number of additional pages, plan price, price for pages outside the plan, 12-month history
 - Checking the ink levels of the black, cyan, magenta, and yellow cartridges
 - Custom widget
